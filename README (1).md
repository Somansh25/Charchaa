# Charchaa Speciality Coffee Shop Brand Application

A premium minimalist, third-wave coffee shop web experience created exclusively for **Charchaa**. Built on a mobile-first philosophy using modern custom CSS grids, layout durability logic, and zero runtime tracking footprints.

## Application Launch Instructions

1. Ensure Python 3.10+ is installed and available in your path.
2. Create a virtual environment:
   ```bash
   python3 -m venv venv
   ```
3. Activate the virtual environment:
   - **macOS/Linux**: `source venv/bin/activate`
   - **Windows**: `venv\Scripts\activate`
4. Initialize and configure local environments by parsing dependency manifests:
   ```bash
   pip install -r requirements.txt
   ```
5. Run the application:
   ```bash
   python app.py
   ```
